# NeuroCuore — Releases

**NeuroCuore** checks how the AI coding agents on a company's Macs are set up
(Claude Code, Cursor, Codex, Copilot and others), holds them against the
company's own policy, and sends the company a report sealed to its key. It
reads settings only and never blocks an agent.

🌐 **Website:** **https://neurocuore.dev**

## ⬇️ Download

The newest build is on the [**Releases**](../../releases/latest) page:

- **macOS** — notarized `.dmg` (Apple Silicon), for a person joining by invite
- **macOS** — signed, notarized `.pkg`, for IT installing through an MDM

NeuroCuore **updates itself**; a company can set a minimum version in its
dashboard, and IT can pin or switch off updates through its MDM.
